## 1. 设置页 API 的联通状态只有「绿 / 红」两档，缺「黄」档

AGENTS.md 要求：设置里涉及的每个 API 都要有测试按钮，并指示联通状态（红=连不通、黄=能连但 key/参数可能错、绿=成功）。当前实现：

| API | 测试入口 | 现状 |
| --- | --- | --- |
| Aria2 RPC（每套配置） | 设置页卡片「测试」按钮，保存后自动测 | `.aria2-test-msg.ok`（绿）/ `.err`（红），**没有黄** |
| 夸克 Cookie | 「手工 Cookie」tab 的「测试」 | `#login-msg` 成功 / 失败两种文案，**没有黄** |
| 夸克扫码登录 | 「生成二维码」+ 轮询状态 | 是登录流程，不是 API 探活 |

缺的「黄」档该覆盖什么（建议）：

- Aria2：RPC 能连（`getVersion` 成功）但**下载目录写不进去** —— 我们踩过 `errorCode=16/18`（远端容器 `/downloads` 只读），这类问题现在要等真下载失败了才暴露；
- 夸克：Cookie 有效（`/1/clouddrive/member` 200）但**配额已满 / 账号类型受限**（例如 23018 单文件超限、`use_capacity≈total_capacity`）。
