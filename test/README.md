# 测试文件说明

这个目录包含了三个测试文件，用于测试项目的各个API组件。

## 测试文件列表

### 1. test_aria2.py
测试 Aria2 下载服务API功能。

**测试内容：**
- 获取当前正在执行的任务
- 获取等待中的任务
- 获取已完成的任务
- 获取暂停/错误/已移除的任务

**使用方法：**
```bash
python test/test_aria2.py
```

**配置要求：**
- 需要运行中的 Aria2 服务
- 在代码中配置正确的 `aria2_host` 和 `aria2_secret`

### 2. test_openlist.py
测试 OpenList 文件管理API功能。

**测试内容：**
- 列出指定目录下的文件和文件夹
- 显示文件大小和类型统计
- 测试多个目录路径

**使用方法：**
```bash
python test/test_openlist.py
```

**配置要求：**
- 需要运行中的 OpenList 服务
- 在代码中配置正确的 `openlist_host` 和 `openlist_token`

### 3. test_quark.py
测试 Quark 网盘API功能。

**测试内容：**
- 获取网盘可用空间
- 列出网盘中的所有文件
- 统计文件类型和大小
- 计算总容量和使用情况

**使用方法：**
```bash
python test/test_quark.py
```

**配置要求：**
- 需要有效的 Quark 网盘 cookie
- 在代码中配置正确的 `cookie` 等参数

## 注意事项

1. **配置参数**：每个测试文件中的配置参数都是示例值，需要根据实际情况修改。

2. **依赖服务**：运行测试前确保相关服务（Aria2、OpenList、Quark）正在运行。

3. **权限要求**：Quark API 需要有效的登录凭据。

4. **网络连接**：确保网络连接正常，能够访问相关服务。

## 输出示例

每个测试文件都会输出详细的测试结果，包括：
- 任务状态统计
- 文件列表
- 容量使用情况
- 错误信息（如果有）

## 故障排除

如果测试失败，请检查：
1. 服务是否正在运行
2. 配置参数是否正确
3. 网络连接是否正常
4. 认证信息是否有效
